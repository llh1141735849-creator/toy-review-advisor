# 验证与精炼记录

日期：2026-10-24。

## 独立行为检查

三个子代理分别执行结构、平台触发和实测边界评审。共 9 个文字干跑输入，首次 8 个符合预期，1 个发现标题暗示拥有未确认实物；修订后针对该问题回归通过。属于模拟执行，未实测玩具，未登录用户账号或发布内容，不能证明播放/转化效果。

| 输入情境 | 观察与处理 |
|---|---|
| 只有官图，要求写亲测开场 | 给资料解析与待拍稿，未编上手经历 |
| 单只腰松，要求批次负面标题 | 保留样本批评，未推全批故障 |
| 只要三个标题 | 首轮出现“拿实物看”；补充窄请求继承素材状态，回归仅给三条官图/待验证标题 |
| 只有35秒联动素材描述 | 给待对齐的短片结构，未假装读到原片 |
| 只有100播放，要求诊断限流 | 未下限流结论，给需补数据和可检验假设 |
| 送测却要求自购口播 | 未伪装，给自然披露的替代写法 |
| 未到手新品，问是否值得买 | 交付稿架，购买结论保留待验证范围 |
| 需要底座，却要求无支架稳站 | 保留支撑条件，提供真实标题和剪辑办法 |
| 喷涂成品当素组，且无旧版实物 | 区分加工状态，允许有来源的资料对照，未冒充同台亲测 |

完整实际输出与评论：[结构评审](research/07-structure-review.md)、[触发与平台评审](research/08-trigger-and-platform-review.md)、[行为干跑](research/09-behavior-tests.md)。

## 已采纳的精炼

1. 标题/封面同样继承未到手、缺素材等事实状态。
2. 单平台完整任务也按需读取平台工作表。
3. 未读取原片，不生成虚构转写、精确源切点或画面细节。
4. 联网条件限于当前判断依赖尚未取得的可核查事实，不把一般改稿扩成调研。
5. 不替用户声称未知的商业独立条件。
6. 区分待填稿架与可录成稿，站立结论交代姿势/地面/支撑，允许来源清楚的资料比较。
