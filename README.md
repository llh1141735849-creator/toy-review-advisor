# 玩具评测内容顾问

面向成人收藏玩具的可复用 AI 内容顾问，覆盖特摄道具、可动机甲、变形玩具与拼装模型，适配 B 站和抖音。

## 可以帮什么

- 选题与账号栏目：从玩家关心的问题出发，确定值得拍的内容。
- 实测设计：把造型、可动、变形、声光、联动和拼装体验转成具体操作与镜头。
- 内容制作：整理核心观点、口播、分镜、标题及封面方向。
- 购买判断：说明适合谁、需要接受什么取舍，以及版本和价格条件。
- 内容复盘：基于真实后台数据提出可验证的改进。

## 使用

将这个仓库作为一个完整的技能文件夹使用，保留 `SKILL.md`、`agents/` 和 `references/` 的相对结构。

例如，在 Codex 中将仓库放到 `~/.codex/skills/toy-review-advisor/`，然后调用：

```text
用 $toy-review-advisor，帮我为这款机甲设计实测重点，以及 B 站评测和抖音短视频方案。
```

也可以提出更小的请求：

```text
这款变身器还没到手，只有官方图。帮我列出到手后最值得验证的三个问题。
```

```text
我已经测过这只样本，需要底座才能保持这个姿势。帮我写三个真实准确的抖音标题。
```

提供完整型号、版本、已有观察和素材，可以得到更具体的建议。

## 方法与边界

框架包含六个核心判断方法和八条实用规则。重点是让判断对应证据，区分官方资料、真实实测、个人喜好和待验证内容。

未拿到玩具时只写资料解析和测试计划；不虚构上手经历，不从单样本推断整批问题，不把剪辑建议说成平台算法，不保证流量或升值。

本项目经过九个独立文字模拟场景检查，并对发现的问题完成修订回归；尚未验证真实账号的长期效果。
